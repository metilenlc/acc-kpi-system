# ACC KPI Framework

## Техническая документация проекта

Версия: **2.0.0-alpha**

---

# Назначение

Каталог **docs** содержит всю техническую документацию проекта.

Документы в этом каталоге являются **единственным актуальным источником технической информации**.

Изменения архитектуры, стандартов разработки и процессов должны вноситься сначала в документы данного каталога, а затем в код проекта.

---

# Структура документации

| Документ           | Назначение                     |
| ------------------ | ------------------------------ |
| README.md          | Обзор технической документации |
| ARCHITECTURE.md    | Архитектура проекта            |
| CODING_STANDARD.md | Стандарты разработки           |
| TASKS.md           | Текущие задачи и спринты       |
| PROJECT_STATE.md   | Текущее состояние проекта      |
| ROADMAP.md         | План развития                  |
| DECISIONS.md       | Архитектурные решения (ADR)    |
| CHANGELOG.md       | История изменений              |
| RELEASES.md        | История релизов                |

---

# Правила работы с документацией

1. Документация хранится в Git вместе с исходным кодом.
2. Любое архитектурное изменение сопровождается обновлением документации.
3. Документы не содержат черновиков и незаполненных разделов.
4. Каждый документ имеет конкретную ответственность.
5. История изменений хранится в Git, а не внутри документов.

---

# Жизненный цикл разработки

```text
Задача
    ↓
Архитектурный анализ
    ↓
Изменение документации (если требуется)
    ↓
Изменение кода
    ↓
Тестирование
    ↓
Git Commit
    ↓
clasp push
    ↓
Проверка в Google Sheets
    ↓
Завершение задачи
```

---

# Правила сопровождения

Документация должна оставаться синхронизированной с кодом проекта.

Если документ перестал соответствовать реализации, его необходимо обновить в рамках той же задачи.

---

# Источник истины

Для разработки используются только документы, расположенные в каталоге **docs**.

Google Docs могут использоваться для обсуждения, согласования или передачи информации, но не являются источником актуальной технической документации.
