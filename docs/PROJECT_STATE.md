# Известный технический долг

## Высокий приоритет

- Магические числа в Builder.
- Магические числа в Calculations.
- Координаты используются напрямую.
- Часть расчётов находится в формулах Google Sheets.
- Строковые литералы не централизованы.

---

## Средний приоритет

- Не все функции используют Geometry API.
- Не завершён Layout Framework.
- Не завершена система констант.

---

# Цель текущего релиза

Завершить Architecture v2.0.

После завершения должно быть обеспечено:

- отсутствие магических чисел;
- отсутствие строковых литералов;
- единый источник геометрии;
- единый источник констант;
- отсутствие координат в рабочих функциях;
- перенос расчётов из шаблона в Apps Script.
