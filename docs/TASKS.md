# Правила

- В работе находится только **одна** задача.
- Новая задача начинается только после завершения предыдущей.
- Каждая задача имеет уникальный идентификатор.
- После завершения задача переводится в раздел "Выполнено".
- Каждая задача завершается тестированием.
- После завершения задачи выполняется Git Commit.
